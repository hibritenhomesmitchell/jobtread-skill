# JobTread Webhook Event Types

These are the event types that can be subscribed to via webhooks. Pass
them as the `eventTypes` array when creating a webhook.

## Account Events
- `accountCreated` — A new account (customer or vendor) was created
- `accountDeleted` — An account was deleted
- `accountUpdated` — An account was updated

## Comment Events
- `commentCreated` — A comment was created
- `commentDeleted` — A comment was deleted
- `commentUpdated` — A comment was updated

## Contact Events
- `contactCreated` — A new contact was created
- `contactDeleted` — A contact was deleted
- `contactUpdated` — A contact was updated

## Daily Log Events
- `dailyLogCreated` — A daily log was created
- `dailyLogDeleted` — A daily log was deleted
- `dailyLogUpdated` — A daily log was updated

## Document Events
- `documentCreated` — A document was created
- `documentDeleted` — A document was deleted
- `documentUpdated` — A document was updated
- `documentSent` — A document was sent to a recipient

## Document Payment Events
- `documentPaymentCreated` — A document payment was created
- `documentPaymentDeleted` — A document payment was deleted
- `documentPaymentUpdated` — A document payment was updated

## Document Recipient Events
- `documentRecipientCreated` — A document recipient was created
- `documentRecipientDeleted` — A document recipient was deleted
- `documentRecipientUpdated` — A document recipient was updated

## File Events
- `fileCreated` — A file was created
- `fileUpdated` — A file was updated
- `fileDeleted` — A file was deleted

## Form Submission Events
- `formSubmissionCreated` — A form submission was created
- `formSubmissionDeleted` — A form submission was deleted
- `formSubmissionUpdated` — A form submission was updated

## Job Events
- `jobCreated` — A new job was created
- `jobDeleted` — A job was deleted
- `jobUpdated` — A job was updated

## Location Events
- `locationCreated` — A location was created
- `locationDeleted` — A location was deleted
- `locationUpdated` — A location was updated

## Payment Events
- `paymentCreated` — A payment was created
- `paymentDeleted` — A payment was deleted
- `paymentUpdated` — A payment was updated

## Task Events
- `taskCreated` — A task was created
- `taskDeleted` — A task was deleted
- `taskUpdated` — A task was updated

## Time Entry Events
- `timeEntryCreated` — A time entry was created
- `timeEntryDeleted` — A time entry was deleted
- `timeEntryUpdated` — A time entry was updated
